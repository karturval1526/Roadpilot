# RoadPilot — GitHub Pages

1. Sube TODOS los archivos de esta carpeta a la raíz del repositorio.
2. GitHub Pages debe publicar desde `main` y `/(root)`.
3. El archivo `index.html` debe quedar directamente en la raíz.
4. No subas el ZIP dentro del repositorio: primero descomprímelo.
5. Los valores de Supabase/Uber del archivo `supabase-config.js` son marcadores seguros y deben reemplazarse cuando conectemos esas funciones.

La versión visual es autocontenida: no depende de una carpeta `assets`.
